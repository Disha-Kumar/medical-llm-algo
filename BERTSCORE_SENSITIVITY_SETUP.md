(Safety) |\n| **Sensitivity** | Correct_Accepted / Total_Correct | Of correct cases, how many were accepted? (Coverage) |\n| **F1 Score** | 2 × (P × S) / (P + S) | Balanced metric (0-1) |\n| **Acceptance Rate** | Accepted / Total × 100 | % of cases that pass threshold |\n| **Diagnosis Flip** | Flips_in_Accepted / Accepted × 100 | % with changing diagnosis across windows |\n| **Hallucination Rate** | Hallucinations / Accepted × 100 | % with detected hallucinations |\n\n**Clinical Implications:**\n- ⬆️ **High threshold** → High precision (safe) but low sensitivity (misses cases)\n- ⬇️ **Low threshold** → High sensitivity (catches cases) but low precision (false positives)\n- 🎯 **Optimal threshold** balances both (typically F1 maximized)\n\n---\n\n## 📚 File Structure\n\n```\nmedical-llm-algo/\n├── src/evaluation/\n│   ├── bertscore_config.py           ← ✨ NEW: Threshold configuration\n│   ├── bertscore_sensitivity.py      ← ✨ NEW: Analysis framework (600+ lines)\n│   ├── bertscore_integration.py      ← ✨ NEW: Integration utilities\n│   ├── harness.py                    (TODO: Integrate threshold gating)\n│   ├── hallucination.py\n│   ├── calibration.py\n│   └── conditions.py\n├── examples/\n│   └── bertscore_sensitivity_example.py  ← ✨ NEW: Runnable example\n├── BERTSCORE_THRESHOLD_METHODOLOGY.md    ← ✨ NEW: Full methodology (350+ lines)\n├── BERTSCORE_SENSITIVITY_SETUP.md        ← YOU ARE HERE\n└── ...\n```\n\n---\n\n## 🎓 Understanding the Framework\n\n### CaseEvaluation\nEach case in your evaluation data:\n```python\nCaseEvaluation(\n    case_id=\"case_001\",              #
