# Multimodal Medical LLM Robustness

## Overview
This project studies robustness and spurious correlations in multimodal medical LLMs using controlled perturbations.

## Objectives
- Detect shortcut learning in medical models
- Analyze diagnostic instability
- Link spurious correlation to hallucination

## Project Structure
- `src/` → core implementation
- `data/` → datasets
- `experiments/` → configs, logs, results
- `docs/` → literature review & reports
- `notebooks/` → analysis
